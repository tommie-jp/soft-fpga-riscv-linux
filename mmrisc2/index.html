soft-fpga-riscv-linux

mmRISC-2 で Linux

RV64GC コア mmRISC-2 の RTL を Verilator で C++ にし、Wasm にした模型です。 PC で起動を済ませて保存した状態を読み戻し、BusyBox のシェルから始めます。 ls などを打てます。1 クロックずつ回しているので、応答は数秒かかります。

準備中

CPU の中 (Logic Analyzer)

1 クロックごとの退役・トラップ・TLB ミス・主記憶の読み書き・UART を記録しています (直近 8192 クロック)。 ⚙ Trigger のプリセット「打鍵」を選んで Set し、端末で字を打つと、その字が入った瞬間からの波形で止まります。
